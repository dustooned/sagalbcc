Quick start

  1. Open SAGA, type your name and the class password (ask your instructor).
  2. Host creates a room. Everyone else joins with the room code or the invite link.
  3. Load your kit from Kit Forge: drag the .kittable.json onto the table.
  4. Play. Everyone sees every move live.
Tap ✕ (top right) to hide all panels for a clear view; ☰ brings them back. The 🧰 Table tools panel folds shut from its header.

Adding things to the table

📦 Load kit…A .kittable.json from Kit Forge's Send to Table or Export ZIP.
🖼️ Add image…Any PNG/JPG/WebP becomes a piece. Fastest way to test one idea.
🧊 Add 3D model…A .glb, .obj or .stl. See File formatsAnimated3D models.
🎨 Table look → BackgroundSpace, nebula and gradient presets, your own gradient or image, plus a Wave or Kaleidoscope effect. Atmosphere adds fog, desert dust, rain, snow or embers with a strength slider. Everyone sees the same look.
Markers & notes+1, −1, DMG, STATUS, custom labels, notes, and dice.
Drag & dropDrop any of the files above anywhere on the page.

Clear table is host-only.

Mouse & keyboard

Left-drag a pieceMove it. Shift+click adds to a selection.
Shift+drag empty tableDraw a box to select every piece inside it, added to what's already selected. Ctrl+drag (⌘ on Mac) does the same but can start on top of a piece. A plain drag on the table does nothing. Cards sitting on a board don't pick up the board. Ctrl+A selects everything.
Right-click a piecePiece menu (flip, rotate, tap, delete…). With several selected: shuffle or gather them into one stack, or turn them all face up / face down. 3D models: stand upright, upside down, on their side or front.
Right-click the tableTable menu and shortcut list.
Party panel − / +Change anyone's points. Tap the number to type it. Tables start with one counter. ＋ adds one with your own name (up to 6), − removes the last one (down to none). Tap a counter name to rename it.
Right-drag the table / wheelOrbit / zoom the camera. Hold Space to pan over pieces.

Touch (tablets & phones)

One finger on a pieceMove it. The camera locks while you hold it — for you only.
Double-tap a pieceFlip it.
Hold one finger still, then dragSelect several pieces: after a short buzz, dragging draws a box around them instead of turning the camera. Tap empty table to deselect.
⬚ button (bottom of the screen)Select mode: one finger draws a box around pieces instead of turning the camera. Tap it again to go back.
Hold a piece + twist a second fingerRotate it (each twist step = one turn).
Long-press (most Android devices)Piece menu.
One finger on the tableOrbit. Two fingers: pan and pinch-zoom.

Dice & tokens

Dice: D6 (numbers or dots), D4, D8, D10, D12, D20. Everyone sees the same result.

Click / tapRoll in place.
ShakeHold it and wiggle back and forth, then let go — it rolls.
Flick / throwDrag fast and release. It slides, tumbles and bounces off the rim.

DMG, STATUS and custom tokens can be thrown too — they flip like a coin.

Animated pieces (GIF, WebM, MP4)

Drop a GIF or a short clip on the table (or 🖼️ Add image…) and it plays on the piece for everyone, looping, with no sound.

FormatLimitsTransparency
GIF8 MB · 300 frames · 20 s · 1024 pxYes, everywhere
WebM (VP9)10 MB · 10 s · 1280 pxYes on Chrome, Edge, Firefox. iPhone/iPad can’t show transparent WebM.
MP4 (H.264)10 MB · 10 s · 1280 pxNo — MP4 has no transparency

Clear areas of a token show the table through them. If a file is too long or too big, SAGA tells you exactly what to trim — ezgif.com can resize, cut and convert GIFs and clips for free.

3D models from Blender

Easiest: any .obj or .stl works as-is — it just shows in one plain color. For colors and textures, export .glb with the settings below.

Fastest: the SAGA Blender add-on

Bakes procedural materials, color ramps and textures into one small .glb with one button — no settings to get right.

  1. Download saga_bake_addon.py.
  2. Blender: Edit → Preferences → Add-ons → ⌄ → Install from Disk…, pick the file, tick SAGA Bake & Export.
  3. Select your model, press N, open the SAGA tab, click Bake & Export.
  4. Drop the .glb (saved next to your .blend) onto the table.

Can't install add-ons on a school computer? Use saga_bake.py instead: Scripting tab → Text → Open → ▶ Run.

Or export by hand

In SAGA, the ⓘ next to 🧊 Add 3D model… shows these settings too.

Before exporting

  1. Select only your model (no lights or camera).
  2. Press Ctrl+A → All Transforms.
  3. Check the triangle count: Overlays → Statistics.

Export: File → Export → glTF 2.0

SettingSet to
FormatglTF Binary (.glb) — one file with textures inside
Include☑ Selected Objects
Data → Mesh☑ Apply Modifiers
Data → Compression☐ Off (SAGA can't read Draco)

Size and position don't matter: SAGA scales the model to about 3 inches and sets it on the table.

Troubleshooting

Stuck on loading / "handshake"Reload the page. Check you're online.
"Someone is moving that"Another player is holding it. Wait a second.
Table disappearedThe room closes after 30 minutes with nobody in it, or when the server updates. Reload your kit.
Can't see the table on a phoneTap ✕ to hide panels.
